About CyberThreatMiner & Academic Scope
Course 23PCIT503: Machine Learning Mini Project • Fall 2026
Official Course Problem Statement:
CyberThreatMiner applies Association Rule Mining using the Apriori algorithm to the MITRE ATT&CK Enterprise dataset (enterprise-attack-v19.2.xlsx). The project discovers frequent itemsets of adversarial techniques and generates statistically defensible association rules based on verified relationships between threat groups and their techniques.

Crucial Intelligence Limitations & Ethical Guardrails

  • Non-Causal Associations: An association rule like T1059 (Command Scripting) → T1105 (Ingress Tool Transfer) indicates observational co-occurrence across threat actor dossiers. It does not prove that using T1059 causes an attacker to use T1105.
  • Non-Chronological Sequence: MITRE ATT&CK dossiers aggregate techniques documented over multiple years and separate campaigns. Itemsets do not represent the chronological sequence of an active intrusion.
  • Non-Predictive Intelligence: High confidence does not predict future adversary attacks. It measures historical consistency within documented cyber threat intelligence (CTI).
  • Reporting Bias: CTI reflects public attribution reports. Highly visible techniques (e.g., PowerShell) are more frequently detected and reported than proprietary zero-day exploits.
